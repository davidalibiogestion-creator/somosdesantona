Guía Técnica de Desarrollo y Mantenimiento Futuro

Instrucciones para ampliar la aplicación web de Somos de Santoña SL sin romper la estructura existente ni perder datos.

1. Modelo de Datos y Persistencia

El sistema guarda el estado global bajo la clave somos_santona_v2_db en localStorage.

  • producers: Lista de personal de fábrica.
  • products: Catálogo maestro con stock actualizado.
  • orders: Pedidos con estados 'pending' o 'confirmed'.

2. Google Drive & Apps Script Integration

Para enviar los albaranes directamente a una carpeta en el Drive corporativo: 

// Google Apps Script Deploy
function doPost(e) {
  var item = JSON.parse(e.postData.contents);
  var folder = DriveApp.getFolderById("ID_CARPETA_SANTONA");
  var file = folder.createFile("Albaran_" + item.code + ".json", JSON.stringify(item));
  return ContentService.createTextOutput("OK");
}
